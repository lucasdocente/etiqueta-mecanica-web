# Etiqueta Mecânica Web

Aplicação estática para criar PDFs de etiquetas térmicas de manutenção automotiva.
Todos os dados e modelos ficam no navegador do usuário; não há backend.

## Publicar na Vercel

O projeto já inclui `vercel.json` com `outputDirectory` definido como `dist`.

1. Envie esta pasta para um repositório GitHub.
2. Na Vercel, escolha **Add New → Project** e importe o repositório.
3. Mantenha **Framework Preset: Other** e publique.

Também é possível executar `vercel` nesta pasta usando a CLI oficial. Consulte
`DEPLOY_VERCEL.md` para o passo a passo completo.
